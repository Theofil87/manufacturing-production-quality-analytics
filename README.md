# Manufacturing Production & Quality Analytics

An end-to-end data analytics portfolio project focused on manufacturing production, quality, defects, scrap, and downtime.

## Technology Stack

- Python
- Pandas
- SQL / PostgreSQL
- Jupyter Notebook
- Power BI
- Streamlit
- GitHub

## Project Goals

- Analyze production volume and efficiency
- Monitor quality and defect rates
- Identify major defect categories using Pareto analysis
- Analyze downtime and production losses
- Compare performance across production lines, shifts, and products

## Planned Data Pipeline

```text
Raw Manufacturing Data

        v

        |
        v

        |
        +--------------------+
        |                    |

   Power BI             Streamlit
```
